## 7. Known limitations

- ActionScript 1/2 has no exact source recovery: `scripts/as/` is the decompiler's reconstruction from AVM1 bytecode, `scripts/pcode/` is the authoritative instruction listing. Comments, formatting and original local variable names are not recoverable.
- **XFL symbol coverage.** FFDec's XFL exporter materialises only 222 of 1945 sprite symbols (1723 missing, 919 of them linkage-exported). The selection is not explained by timeline reachability or linkage, so the XFL library is partial by construction. Use `extracted/sprites/` for complete sprite coverage and `extracted/xfl/` for the authored screens.
- `DefineEditText` tags are runtime text fields; their rendered appearance depends on the client's embedded fonts, so `texts/` holds text content, not layout.
- FFDec emits sound files with a duplicated extension (e.g. `1_sfx_14.mp3.mp3`); the inner extension is the real container. Files are kept as emitted so the manifest stays byte-reproducible.
- `-select` is ignored by this FFDec build for sprite export, so the opt-in sprite stage always renders every frame of every sprite.
